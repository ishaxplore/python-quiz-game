Python Quiz Game

An interactive quiz game built using Python and Tkinter. The application fetches quiz questions from an external API and provides a graphical interface where users can answer questions and track their scores.

Features

- Interactive graphical user interface
- Quiz questions fetched using the Open Trivia Database API
- True and False answer buttons
- Score tracking
- Object-Oriented Programming (OOP)
- Interactive question navigation

 Technologies Used

- Python
- Tkinter
- Requests
- Open Trivia Database API

 Project Structure
 
python-quiz-game/

└── false.png


🚀 How to Run
Clone this repository:
git clone https://github.com/ishaxplore/python-quiz-game.git
Open the project folder in PyCharm.
Install the required dependency:
python -m pip install requests
Run the application:
python main.py
